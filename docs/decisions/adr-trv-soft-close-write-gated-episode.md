# Soft-close floor/arm and closed_idle are write-gated on all commissioned closures

On first Plant-on all-idle observe, the App arms `trv_soft_close_hold_s` and sets `_trv_idle_episode` to `holding` only when every commissioned `valve_closure` write of `valve_closure_floor` succeeds; on hold expiry while still idle, it sets `closed_idle` only when every commissioned write of closure `100` succeeds — otherwise episode stays unset/`None` so a later tick can retry. Recorded from story 7.1 plan follow-up Code Review patches F2/F3 and Implementation Notes (`story-tracer-trv-house-idle-soft-close-plan.md`) and commit `90dcc7a`, because arming a hold or claiming `closed_idle` after a partial write would leave sibling TRVs at the wrong limit while the episode short-circuits further soft-close writes.
